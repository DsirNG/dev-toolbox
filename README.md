# dev-toolbox

个人开发工具箱，收录日常开发中自制的插件、脚本和实用工具。

- [Codex Git Diff](codex-git-diff/README.md)：在 Codex 内置浏览器查看本地 Git 变更的双栏对比。
- [WebStorm i18n Translation Helper](webstorm-i18n-inline/README.md)：在 Vue 文件里显示翻译提示，并支持跳转到语言资源。

Each tool has its own setup instructions. Build outputs are ignored; keep source,
installation scripts, and documentation in this repository.
